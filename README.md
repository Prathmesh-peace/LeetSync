# 🚀 LeetSync

Automatically sync accepted LeetCode solutions to GitHub with a Chrome extension.

> **Status:** 🚧 Under active development

---

## ✨ Current Features

- ✅ Chrome Extension built with WXT + React + TypeScript
- ✅ Detect LeetCode problem pages
- ✅ Fetch problem metadata using LeetCode GraphQL API
- 🚧 Detect accepted submissions (In Progress)
- 🚧 Extract submitted code
- 🚧 Automatic GitHub sync

---

## 🛠️ Tech Stack

### Extension
- WXT
- React
- TypeScript

### Backend (Upcoming)
- Node.js
- Express

### APIs
- LeetCode GraphQL API
- GitHub REST API
